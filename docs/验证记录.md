# 验证记录

验证日期：2026-09-28。

## 已通过

- Python 3.11.16 + AgentScope 2.0.9，`uv sync --frozen` 成功。
- 17 项 pytest 测试：金额/状态机、DDD依赖边界、幂等冲突、重复下单/取消、库存竞争、跨买家隔离、偏好确认、购物车revision、REST鉴权、WebSocket重放、队列FIFO/过期租约/fence、关键词降级、向量召回/HTTP重排降级、Markdown切片、真正的KnowledgeBase写入与检索。
- AgentScope 的真实 Agent/FunctionTool 循环通过本地模拟 OpenAI SSE 服务调用，验证工具执行、最终回复、AgentState保存/恢复和system前缀保持不变。不是绕过SDK直接返回固定结果。
- 内置 TaskCreate 经过重复调用和新AgentState重放验证；购物车查询在同轮写入后返回最新状态。
- KnowledgeBase 使用真实 OpenAIEmbeddingModel + QdrantStore（内存后端），对本地embedding测试服务器执行请求，验证实际向量维度探测、文档索引幂等与搜索。
- React 18 + TypeScript严格模式，`npm run build` 成功。
- 8条小型关键词检索样例的macro recall@3为1.000。样例仅覆盖8个种子商品，不代表真实商品库上的泛化能力或向量模型效果。

## 复现

```bash
uv sync --frozen
uv run pytest -q
uv run python -m scripts.check_sdk
uv run python -m eval.run
cd frontend
npm ci
npm run build
```

如果运行环境人为设置了全局SOCKS代理而未安装相关依赖，应为localhost设置NO_PROXY，并安装对应的httpx代理依赖或移除不适用的代理设置。
