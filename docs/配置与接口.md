# 配置与接口

所有设置来自项目根目录 `.env`；Docker Compose 显式覆盖数据库、Redis、Qdrant地址和worker模式。

| 变量 | 用途 |
|---|---|
| APP_MODE | `demo` / `llm` |
| LLM_BASE_URL / LLM_API_KEY / LLM_MODEL | OpenAI兼容 Chat Completions 服务 |
| EMBEDDING_BASE_URL / EMBEDDING_API_KEY / EMBEDDING_MODEL | 独立向量模型服务，默认模型名 text-embedding-v4 |
| RERANKER_URL / RERANKER_API_KEY / RERANKER_MODEL | 可选 HTTP 重排 |
| WEB_SEARCH_PROVIDER / WEB_SEARCH_URL / WEB_SEARCH_API_KEY | 实时网页查询；默认支持 Tavily，限制到京东/淘宝/天猫域名 |
| WEB_SEARCH_DOMAINS | 逗号分隔的允许搜索域名，默认 `jd.com,taobao.com,tmall.com` |
| CONTEXT_WINDOW | 向 SDK 声明的上下文长度，默认16000，应不超过所用模型实际上限 |
| JOB_TIMEOUT | 单次 Agent任务的总超时，默认180秒 |
| DATABASE_URL | SQLAlchemy async SQLite URL |
| REDIS_URL / QDRANT_URL | 空值表示本地开发不连接 |
| INLINE_WORKER | 本地true，独立worker部署false |
| ALLOWED_ORIGINS | CORS和WebSocket Origin白名单，多个地址逗号分隔 |

## 服务契约

### Reranker

POST `RERANKER_URL`，Authorization: Bearer。

```json
{"model":"rerank","query":"降噪耳机","documents":["商品文本1","商品文本2"],"top_n":6}
```

响应：

```json
{"results":[{"index":1,"relevance_score":0.98},{"index":0,"relevance_score":0.87}]}
```

index是原documents的下标，按返回次序排序。非2xx、超时、重复/越界下标均降级。供应商返回格式不同需要在 `infrastructure/search.py` 增加适配，不能只换URL。

### Web search

POST `WEB_SEARCH_URL`，Authorization: Bearer。

```json
{"query":"某目的地进口政策 官方来源","limit":5}
```

响应：

```json
{"results":[{"title":"官方政策页面","url":"https://example.org/policy","snippet":"检索摘要"}]}
```

该接口是可插拔网关契约，并非内置某个网页搜索供应商。未配置或调用失败时返回 available=false，不能据此声称查询过最新政策。

## REST

`POST /api/guest` 返回访问token；其他业务请求带 `Authorization: Bearer TOKEN`。

| 方法 | 路由 | 说明 |
|---|---|---|
| GET | /api/health | 模式、模型、服务存活 |
| GET/POST | /api/sessions | 列出/新建当前买家会话 |
| GET | /api/products?q=耳机 | 商品列表或检索 |
| POST | /api/sessions/{id}/messages | `{text,request_id}`，返回202和job id |
| GET | /api/jobs/{id} | queued/running/done/failed以及结果 |
| GET | /api/sessions/{id}/state | 购物车、订单、偏好、待确认卡片 |
| GET | /api/sessions/{id}/events?after=0 | 按seq分页拉取事件，单批最多300 |
| POST | /api/sessions/{id}/actions | `{action,args,request_id}` |

业务action：cart_set、order_propose、order_cancel、preference_propose、confirm、reject。相同提交重试请复用request_id，不要生成新UUID。

```json
{"action":"cart_set","args":{"product_id":"p01","quantity":1},"request_id":"客户端生成的UUID"}
```

参数错误422；业务状态冲突409；未认证401；跨买家资源统一404。数量整数0–20，0移除。金额字符串避免二进制浮点误差。提案默认15分钟过期；只支持 US/CN/DE 与 USD/CNY/EUR。

## WebSocket

连接 `/api/ws/{session_id}`，10秒内发送首帧：

```json
{"token":"游客token","after":0}
```

服务端推送 `{seq,type,job,data,...}`。刷新后从0重放，重连从最后seq继续。不要在URL中携带密钥。前端忽略 heartbeat 并按seq去重。

## 常见排错

- 顶部显示演示模式：检查 `APP_MODE`，修改后要重建app/worker容器环境，单纯restart不会重新读取Compose env_file。
- 提示向量检索不可用：检查embedding密钥与Qdrant，执行索引脚本；仅有聊天模型密钥不够。
- LLM任务失败：看 `docker compose logs app worker`，检查模型是否支持工具调用、base URL是否含正确API前缀、网络与额度。错误不会把敏感上游HTTP响应发送给前端。
- 一直queued：检查worker是否启动、app/worker是否挂载同一个SQLite卷；本地需开启INLINE_WORKER。
- 报价确认冲突：购物车或库存改变，重新生成报价。
- 浏览器凭证过期：本项目没有正式账号恢复；清除 `globex_token` 后重新加载会创建新游客，旧数据不会自动关联。
- 本地IDE import失败：从项目根运行并选择uv创建的Python解释器，不要直接运行包内某个文件。
- WebSocket被代理阻止：前端会通过REST补拉事件，检查Nginx Upgrade配置和Origin白名单。
